# DevOps Lab 1 – CI/CD Pipeline Implementation

## Project Overview

This repository contains the implementation of DevOps Lab 1, focusing on Linux environment setup, Git version control, Jenkins automation, and Continuous Integration and Continuous Deployment (CI/CD).

The project demonstrates how to configure a Linux-based development environment and automate application build, testing, and deployment using DevOps tools.

## Objectives

- Set up Ubuntu Linux using UTM Virtual Machine on macOS.
- Install and configure essential development tools.
- Understand Git and GitHub version control.
- Install and configure Java and Jenkins.
- Create and manage Jenkins CI/CD pipelines.
- Automate application build and testing.
- Implement application deployment through Jenkins.

- **Host OS:** macOS
- **Processor:** Apple M4
- **Virtualization:** UTM
- **Guest OS:** Ubuntu 24.04.5 LTS
- **Architecture:** ARM64 (aarch64)
- **Allocated RAM:** 4 GB

## Implementation Plan

### Phase 1: Linux Environment Setup
- Install Ubuntu using UTM.
- Update and upgrade system packages.
- Install essential development tools.
- Verify system configuration.

### Phase 2: Git and GitHub
- Configure Git username and email.
- Initialize a local Git repository.
- Create commits and branches.
- Push project files to GitHub.

### Phase 3: Java and Jenkins
- Install Java.
- Install and configure Jenkins.
- Access the Jenkins dashboard.
- Configure required plugins.

### Phase 4: CI/CD Pipeline
- Create a Jenkins pipeline.
- Connect Jenkins with the GitHub repository.
- Configure the Jenkinsfile.
- Automate build and testing stages.

### Phase 5: Application Deployment
- Configure deployment stages.
- Execute the pipeline.
- Verify successful application deployment.
